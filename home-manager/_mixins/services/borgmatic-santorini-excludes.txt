# NOT the Linux-home patterns in borgmatic.nix's rubo77 set — santorini backs
# up the Windows user homes + the PostgreSQL build farm, not the WSL home.
#
# Source roots (see borgmatic-santorini.nix):
#   /mnt/c/Users/gburd
#   /mnt/c/Users/gregb
#   /mnt/c/bf                (build-farm client-code + animal .conf files)
#
# BORG PATTERN SYNTAX (important — got this wrong the first run):
#   borg matches `sh:` (shell-style) patterns against the FULL path, anchored
#   at the start. So `sh:target` matches ONLY a path literally beginning with
#   "target" — it does NOT match /mnt/c/Users/gburd/.../target. To match a
#   directory NAME at ANY depth, anchor to the source root and use `**`:
#   `sh:/mnt/c/**/target` (the `**` spans path separators; `fm:` does not).
#   This mirrors the proven fleet idiom in borgmatic.nix (`sh:${h}/ws/**/target`).
#   Path-anchored excludes use the full absolute path as seen inside WSL.
#
# Rule of thumb: keep sources, configs, scripts, animal .conf; drop anything
# a compiler/package manager/build farm regenerates.
