# Extra borg exclude patterns for santorini (Windows host, backed up from
# inside WSL NixOS via the /mnt/c mounts). These are Windows-path patterns,
# NOT the Linux-home patterns in borgmatic.nix's rubo77 set — santorini backs
# up the Windows user homes + the PostgreSQL build farm, not the WSL home.
#
# Source roots (see borgmatic-santorini.nix):
#   /mnt/c/Users/gburd
#   /mnt/c/Users/gregb
#   /mnt/c/bf                (build-farm client-code + animal .conf files)
#
# Rule of thumb: keep sources, configs, scripts, animal .conf; drop anything
# a compiler/package manager/build farm regenerates. `sh:` patterns match at
# any depth; leading-path patterns are anchored under a source root.

# ---- PostgreSQL build farm: transient build tree (regenerable) -----------
# build-farm.conf sets  build_root => "c:/build"  — 20GB of checked-out
# source + object files, rebuilt from git on every run. Never back it up.

# per-animal ccache / mirror / scratch under the build root live in c:/build
# already (covered above); the .conf files under /mnt/c/bf ARE kept.

sh:/mnt/c/bf/.locks
